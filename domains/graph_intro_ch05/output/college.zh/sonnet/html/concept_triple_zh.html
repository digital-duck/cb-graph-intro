三元组(Triple)

定义。 三元组是由三个有序元素构成的数据单元,记作 $(a, b, c)$。"有序"意味着位置决定含义:$(1,2,3)$ 与 $(3,2,1)$ 是不同的三元组。在知识图谱中,三元组最常见的形式是 $(\text{主语}, \text{谓语}, \text{宾语})$,即"某个对象 通过某种关系 连接到 另一个对象"。例如 $(\text{牛顿}, \text{发现}, \text{万有引力})$。

三元组之所以重要,是因为它用最小的结构表达了一个完整的事实:一个孤立的名词不构成陈述,两个元素只能表示"存在联系",而三个元素才能同时说明"谁、与谁、是什么关系"。许多事实,包括图数据库、语义网(RDF)中的数据,都由大量三元组堆叠而成。

例题。 在数学中,三元组也出现在勾股数里:满足 $a^2 + b^2 = c^2$ 的正整数三元组 $(a,b,c)$。判断 $(5,12,13)$ 是否为勾股三元组:

$$5^2 + 12^2 = 25 + 144 = 169 = 13^2$$

所以它是勾股三元组。再看知识图谱的例子,下面三条事实共同构成一张小图:

  • $(\text{地球}, \text{围绕}, \text{太阳})$
  • $(\text{月球}, \text{围绕}, \text{地球})$
  • $(\text{太阳}, \text{属于}, \text{银河系})$

    • 把每个三元组看成一条带标签的有向边:主语是起点,宾语是终点,谓语是边上的标签。三条边共享节点"地球"和"太阳",于是自然连成一张图。

    问题求解应用。 问题:利用上面三个三元组,回答"月球间接属于哪个星系?"

  • 从 $(\text{月球}, \text{围绕}, \text{地球})$ 出发,得到月球的下一个节点是地球。
  • 由 $(\text{地球}, \text{围绕}, \text{太阳})$,继续到太阳。
  • 由 $(\text{太阳}, \text{属于}, \text{银河系})$,到达银河系。

    • 答案:银河系。这种沿着三元组链条逐步推理的方法称为"多跳查询",是知识图谱问答的核心。

    用代码表示同样简单:

    triples = [("地球","围绕","太阳"),
           ("月球","围绕","地球"),
           ("太阳","属于","银河系")]

def hop(node):
    return [o for s, p, o in triples if s == node]

print(hop(hop(hop("月球")[0])[0])[0])  # 银河系

    小结与练习。 三元组用"主语—谓语—宾语"的固定结构记录事实,多个三元组共享节点即可组成图,并支持多跳推理。练习:再添加一个三元组 $(\text{银河系}, \text{包含}, \text{太阳})$,思考查询"太阳"的出边时结果会有什么变化,并说明为什么谓语方向在建模时必须保持一致。
