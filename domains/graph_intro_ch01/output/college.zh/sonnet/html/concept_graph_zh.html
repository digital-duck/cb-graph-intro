图(Graph)

定义。 图是描述"对象及其相互关系"的数学结构。一个图 $G=(V,E)$ 由顶点集 $V$(对象)和边集 $E$(关系)组成。若边没有方向(如"互为好友"),称为无向图;若边有方向(如"课程A是课程B的先修课"),称为有向图。顶点 $v$ 的度是与它相连的边数,记作 $\deg(v)$。在无向图中,所有顶点度数之和等于边数的两倍:

$$\sum_{v\in V}\deg(v)=2|E|.$$

图的常见存储方式有两种:邻接表(每个顶点存一份邻居列表,适合稀疏图)和邻接矩阵($A_{ij}=1$ 表示 $i$ 到 $j$ 有边,适合稠密图)。

例题。 某校有四门课:微积分(C)、线性代数(L)、概率论(P)、机器学习(M)。先修关系为:C→L,C→P,L→M,P→M。

邻接表为:

  • C: [L, P]
  • L: [M]
  • P: [M]
  • M: []

    • 问:要修机器学习,最少需要先修哪些课?它们的合法修读顺序是什么?

    解:从 M 沿边反向追溯,得到 L 和 P;再追溯得到 C。因此必须先修 C、L、P 三门课。合法顺序需满足每条边的起点先于终点,例如 C, L, P, M 或 C, P, L, M。这种满足所有边方向的排列称为拓扑排序,它只在无环的有向图(DAG)中存在。

    问题求解应用。 许多实际问题都可以先"建图",再用成熟算法求解:

  • 最短路径:地图导航中,路口是顶点,道路是边,边权为距离或时间。无权图用广度优先搜索(BFS)即可求出最少边数的路径。
  • 连通性:判断社交网络中两人是否能通过朋友链相识,即判断两顶点是否在同一连通分量中。可用深度优先搜索(DFS)实现:
    • def reachable(graph, start, goal):
    seen, stack = set(), [start]
    while stack:
        v = stack.pop()
        if v == goal:
            return True
        if v not in seen:
            seen.add(v)
            stack.extend(graph[v])
    return False
  • 依赖检测:若先修关系中出现环(如 A→B→C→A),则任何人都无法修完这些课。用 DFS 检测环,是软件构建系统、任务调度器的基本功能。

    • 小结。 解图问题的关键在于三步:确定什么是顶点、什么是边;选择合适的存储方式;再套用 BFS、DFS 或拓扑排序等算法。把陌生问题转化为图,往往就解决了一大半。
