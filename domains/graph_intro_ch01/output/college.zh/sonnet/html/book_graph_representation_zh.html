收获

经过前面各节的铺垫,我们终于来到图表示(graph representation)。它是整本书自然的终点:前面学过的每一个概念,都可以看成图中的一个节点;每一条"先修关系""依赖关系""调用关系",都是图中的一条边。图表示把零散的知识、流程与数据,统一成一种可以计算的结构。

一、图表示实现了什么

定义。 图表示是用节点集合 $V$ 与边集合 $E$ 来描述对象及其关系,记作 $G=(V,E)$。它是一种建模方式,不是一条需要证明的定理。常见的存储形式有两种:

  • 邻接表:对每个节点,记录它指向的所有节点;
  • 邻接矩阵:用矩阵 $A$ 表示,若存在边 $i\to j$,则 $A_{ij}=1$,否则为 $0$。

    • 为什么它是终点。 之前的概念(列表、字典、递归、队列、遍历)在这里汇合:邻接表就是字典加列表,遍历就是递归或队列。一旦关系被写成图,就可以用同一套算法回答不同领域的问题。

    二、工作示例:学习路径

    假设有下列先修关系(箭头表示"先学"):

    graph = {
    "向量": ["内积"],
    "内积": ["正交", "投影"],
    "正交": ["格拉姆-施密特"],
    "投影": ["格拉姆-施密特"],
    "格拉姆-施密特": [],
}

def prerequisites(target, graph):
    # 反向查找:谁指向 target
    result, stack = set(), [target]
    while stack:
        cur = stack.pop()
        for u, outs in graph.items():
            if cur in outs and u not in result:
                result.add(u)
                stack.append(u)
    return result

print(prerequisites("格拉姆-施密特", graph))
# {'向量', '内积', '正交', '投影'}

    要学"格拉姆-施密特",必须先掌握这四个概念。只需几行代码,我们就把一个"该学什么"的问题变成了图上的可达性问题。

    三、与各应用领域的联系

    本节没有列出具体的应用清单,下面用三类典型场景说明同一个模型如何迁移:

  • 知识与课程规划:节点是概念,边是先修关系。拓扑排序给出合理的学习顺序,上面的反向搜索给出个性化路径。
  • 工作流与程序分析:节点是任务或函数,边是调用或数据依赖。检测环,就能发现死锁或循环依赖;并行执行没有互相依赖的分支。
  • 网络与推荐:节点是人或物品,边是交互。最短路径衡量"几步之遥",度数与中心性衡量影响力。

    • 三者的共同点是:先问"有哪些对象、它们之间有什么关系",再选择算法。
