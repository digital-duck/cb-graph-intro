Clustering Coefficient Random Graphs

The clustering coefficient of a node measures how tightly its neighbors are connected to each other — in other words, what fraction of possible "friend-of-a-friend" connections actually exist. For a node $v$ with degree $k$, there are $\binom{k}{2}$ potential edges among its neighbors. If $e_v$ of those edges are present, the local clustering coefficient is:

$$C(v) = \frac{e_v}{\binom{k}{2}} = \frac{2e_v}{k(k-1)}$$

The global clustering coefficient $\bar{C}$ is simply the average of $C(v)$ over all nodes with degree $\geq 2$.

Why random graphs matter here. The Erdős–Rényi random graph $G(n, p)$ places an edge between every pair of the $n$ nodes independently with probability $p$. For any node $v$ with neighbors $u$ and $w$, the probability that the edge $(u, w)$ exists is exactly $p$ — independently of everything else. Since each potential neighbor-pair edge appears with probability $p$, the expected clustering coefficient is:

$$\mathbb{E}[\bar{C}] = p$$

For a graph with $n = 1000$ nodes and $p = 0.01$, the expected average degree is $(n-1)p \approx 10$, and the expected clustering coefficient is just $0.01$ — quite low.

Worked example. Suppose you observe a social network with 500 nodes, average degree 20, and $\bar{C} = 0.35$. An Erdős–Rényi graph with the same density would have $p \approx 20/499 \approx 0.04$, predicting $\bar{C} \approx 0.04$. The observed value of $0.35$ is nearly nine times larger — a strong signal that the network is not random. Real social networks cluster because your friends tend to know each other; random graphs do not have this property.

Applying this in practice. This comparison is a standard diagnostic in network analysis. Generate a null model — a random graph with the same number of nodes and edges — compute its expected clustering coefficient ($\approx p$), then compare to the real network's $\bar{C}$. A ratio $\bar{C}_{\text{real}} / \bar{C}_{\text{random}} \gg 1$ indicates meaningful community structure worth investigating further. Tools like NetworkX make this concrete:

import networkx as nx
G_real = nx.karate_club_graph()
C_real = nx.average_clustering(G_real)
n, m = G_real.number_of_nodes(), G_real.number_of_edges()
p = 2 * m / (n * (n - 1))
print(f"Real: {C_real:.3f}  Random baseline: {p:.3f}  Ratio: {C_real/p:.1f}x")

The clustering coefficient of a random graph thus serves as a baseline that transforms an abstract network statistic into a meaningful, interpretable signal about real-world structure.
