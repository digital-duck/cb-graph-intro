强连通定向

定义。 给定一个无向图 $G$,若能为每条边指定一个方向,使得得到的有向图中任意两个顶点 $u,v$ 之间都存在从 $u$ 到 $v$ 的有向路径(即该有向图是强连通的),则称这种指定方向的方法为 $G$ 的强连通定向。

直观地说:把每条街道改成单行道之后,从城市任意一点出发,仍然可以开车到达任意另一点。

判定条件(Robbins 定理)。 连通无向图 $G$ 存在强连通定向,当且仅当 $G$ 没有桥(即 $G$ 是 2-边连通的)。原因很直观:桥是连接两部分的唯一通道,一旦给它定向,就只能单向通行,另一侧永远无法返回。反过来,没有桥的图可以通过"耳分解"逐步构造:先取一个圈并把它定成环形方向,再把每个新增的"耳"(一条路径)沿同一方向接上,强连通性始终保持。

例题。 判断下图能否强连通定向:顶点 $\{1,2,3,4\}$,边为 $12,\,23,\,31,\,34$。

边 $34$ 是桥,删去它后顶点 4 与其余部分分离,因此不能定向。若再添加一条边 $41$,则 $G$ 无桥,可以定向:取圈 $1\to2\to3\to1$,再取耳 $1\to4\to3$?注意这里应让耳从圈上一点出发、回到圈上另一点。边 $34$ 与 $41$ 构成从 3 到 1 经过 4 的路径,定为 $3\to4\to1$。此时 4 可由 3 到达,也能到达 1,整张图强连通。

问题求解应用。 算法上可用深度优先搜索(DFS)实现:

  • 从任意顶点出发做 DFS,树边定向为"父 $\to$ 子"。
  • 遇到非树边(回边)时,定向为"后代 $\to$ 祖先"。
  • 若某棵子树内没有回边越过其根的父边,则该父边是桥,无解。
    • def orient(G):
    seen, order, low, res = set(), {}, {}, []
    def dfs(u, p):
        order[u] = low[u] = len(order); seen.add(u)
        for v in G[u]:
            if v == p: continue
            if v not in seen:
                res.append((u, v)); dfs(v, u)
                low[u] = min(low[u], low[v])
                if low[v] > order[u]: raise ValueError("有桥")
            elif order[v] < order[u]:
                res.append((u, v)); low[u] = min(low[u], order[v])
    dfs(next(iter(G)), None)
    return res

    该算法时间复杂度为 $O(V+E)$。实际应用包括城市单行道规划、通信网络中链路方向设计等:先检验有无桥,再按上述规则定向,即可保证任意两点互通。
