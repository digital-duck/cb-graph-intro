有向图

定义。 有向图(directed graph,digraph)是由顶点集 $V$ 和有向边集 $E$ 组成的结构 $G=(V,E)$,其中每条边是一个有序对 $(u,v)$,表示从 $u$ 指向 $v$。与无向图不同,$(u,v)$ 与 $(v,u)$ 是两条不同的边。常用概念如下:

  • 出度 $\deg^+(v)$:从 $v$ 出发的边数;入度 $\deg^-(v)$:指向 $v$ 的边数。
  • 路径:沿边方向依次经过的顶点序列。
  • 环:起点与终点相同的路径。没有环的有向图称为有向无环图(DAG)。

    • 对任意有向图,所有顶点的出度之和等于入度之和,都等于边数:

    $$\sum_{v\in V}\deg^+(v)=\sum_{v\in V}\deg^-(v)=|E|.$$

    原因很直接:每条边恰好有一个起点和一个终点。

    例题。 设课程先修关系为 $V=\{A,B,C,D\}$,$E=\{(A,B),(A,C),(B,D),(C,D)\}$,其中 $(u,v)$ 表示"先学 $u$ 才能学 $v$"。

  • 出度:$A$ 为 2,$B$ 为 1,$C$ 为 1,$D$ 为 0。
  • 入度:$A$ 为 0,$B$ 为 1,$C$ 为 1,$D$ 为 2。
  • 两者之和都是 4,等于 $|E|=4$,验证通过。
  • 从 $A$ 到 $D$ 有两条路径:$A\to B\to D$ 与 $A\to C\to D$。
  • 没有任何路径能从 $D$ 回到 $A$,所以这是一个 DAG。

    • 问题求解应用:排课顺序(拓扑排序)。 要给上述课程安排一个合法的学习顺序,可以反复执行以下步骤:

  • 找出入度为 0 的顶点,把它加入顺序。
  • 删除该顶点及其出边,更新其余顶点的入度。
  • 重复,直到图为空。

    • 对本例:先取 $A$(入度 0)。删除 $A$ 后,$B$ 和 $C$ 的入度变为 0,依次取出。最后 $D$ 的入度变为 0。得到顺序 $A,B,C,D$(或 $A,C,B,D$)。

    如果某一步找不到入度为 0 的顶点而图仍非空,说明图中存在环,例如 $B\to C\to B$,表示课程互为先修,无法排出合法顺序。因此,这个算法既能给出排序,也能检测环。

    用 Python 表示并计算入度:

    edges = [("A","B"),("A","C"),("B","D"),("C","D")]
indeg = {v: 0 for v in "ABCD"}
for u, v in edges:
    indeg[v] += 1
print(indeg)  # {'A': 0, 'B': 1, 'C': 1, 'D': 2}

    小结。 只要关系带有方向,例如依赖、流程、网页链接或任务调度,就可以用有向图建模。判断时先看有没有环,再用度数和路径回答具体问题。
