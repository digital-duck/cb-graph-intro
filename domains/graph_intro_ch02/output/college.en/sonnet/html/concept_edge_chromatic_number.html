Edge Chromatic Number

The edge chromatic number of a graph $G$, written $\chi'(G)$, is the minimum number of colors needed to color every edge of $G$ so that no two edges sharing a vertex receive the same color. This is distinct from vertex coloring: here the constraint is on edges meeting at a common endpoint, not on adjacent vertices.

A key theoretical anchor is Vizing's Theorem: for any simple graph $G$ with maximum degree $\Delta(G)$, the edge chromatic number satisfies

$$\Delta(G) \leq \chi'(G) \leq \Delta(G) + 1.$$

This means every graph falls into exactly one of two classes. Class 1 graphs achieve $\chi'(G) = \Delta(G)$; Class 2 graphs require one extra color. Complete graphs $K_n$ with $n$ even are Class 1; complete graphs with $n$ odd are Class 2.

Worked example. Consider $K_4$, the complete graph on four vertices. Each vertex has degree 3, so $\Delta(K_4) = 3$. Vizing's theorem says $\chi'(K_4) \in \{3, 4\}$. Label the vertices $1, 2, 3, 4$. Assign colors as follows:

  • Color 1: edges $\{1,2\}$ and $\{3,4\}$
  • Color 2: edges $\{1,3\}$ and $\{2,4\}$
  • Color 3: edges $\{1,4\}$ and $\{2,3\}$

    • Every vertex touches exactly one edge of each color, and no two edges at the same vertex share a color. Three colors suffice, confirming $\chi'(K_4) = 3$, so $K_4$ is Class 1.

    Problem-solving application. Edge coloring models scheduling problems where shared resources create conflicts. Suppose five teams must each play every other team once in a tournament. The schedule forms $K_5$; each vertex has degree 4, so $\Delta = 4$. Since $K_5$ has an odd number of vertices, it is Class 2, giving $\chi'(K_5) = 5$. This tells you immediately that at least five rounds are required — no clever bracket can compress it to four. Each color class is a set of games that can be played simultaneously (no team appears twice), which is exactly one round. The edge chromatic number thus gives a provable lower bound on the tournament length before you ever try to build the schedule.
