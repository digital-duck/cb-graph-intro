哈密顿图

定义。 在图 $G=(V,E)$ 中,若存在一条经过每个顶点恰好一次的路径,称为哈密顿路径;若这条路径还能回到起点,形成闭合回路,则称为哈密顿回路。含有哈密顿回路的图叫做哈密顿图。

注意它与欧拉回路的区别:欧拉回路要求每条边恰好经过一次,有简洁的判定条件(所有顶点度数为偶数且连通);哈密顿回路要求每个顶点恰好经过一次,至今没有简单的充要条件,判定问题是 NP 完全的。

例题。 判断立方体图 $Q_3$(8 个顶点,每个顶点用 3 位二进制串表示,仅相差一位的两个顶点相邻)是否为哈密顿图。

构造如下:沿着格雷码的顺序走:

$$000 \to 001 \to 011 \to 010 \to 110 \to 111 \to 101 \to 100 \to 000$$

相邻两项只差一位,所以每一步都是图中的一条边;8 个顶点各出现一次,最后又回到 $000$。因此 $Q_3$ 是哈密顿图。

再看反例:一个二部图,两部分顶点数分别为 3 和 4。哈密顿回路上的顶点必须在两部分之间交替出现,因此两部分的顶点数必须相等。$3\neq 4$,所以该图没有哈密顿回路。

问题求解应用。 实际中常用以下方法:

  • 找必要条件排除。 若图中有度数为 1 的顶点,则不可能有哈密顿回路(回路中每个顶点至少需要 2 条边)。若删去 $k$ 个顶点后,图分裂成超过 $k$ 个连通分支,也不可能是哈密顿图。
  • 用充分条件确认。 狄拉克定理:若 $n\ge 3$ 个顶点的简单图中,每个顶点的度数都满足 $\deg(v)\ge \dfrac{n}{2}$,则该图是哈密顿图。例如,6 个顶点、每个顶点度数至少为 3 的图,必为哈密顿图。注意这只是充分条件:长度为 $n$ 的圆环图每个顶点度数仅为 2,却显然是哈密顿图。
  • 回溯搜索。 当条件无法判定时,用深度优先搜索逐步延伸路径,遇到死路就回退:
    • def ham_cycle(adj, path):
    n = len(adj)
    if len(path) == n:
        return path[0] in adj[path[-1]]
    for v in adj[path[-1]]:
        if v not in path:
            if ham_cycle(adj, path + [v]):
                return True
    return False

    调用 ham_cycle(adj, [0]) 即可。最坏情况需要检查约 $(n-1)!$ 条路径,因此只适用于规模较小的图。

    典型应用包括旅行商问题(在完全图上寻找最短的哈密顿回路)、DNA 片段拼接,以及格雷码的构造。
