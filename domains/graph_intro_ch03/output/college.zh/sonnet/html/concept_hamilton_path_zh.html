Hamilton 路径

定义。 在图 $G=(V,E)$ 中,Hamilton 路径是一条恰好经过每个顶点一次的路径。若它的起点和终点之间还有一条边,把路径首尾连起来,就得到 Hamilton 圈。

别把它和 Euler 路径混淆:Euler 路径要求每条边恰好走一次,Hamilton 路径要求每个顶点恰好走一次。前者有简单的判定法则(看奇度顶点的个数),后者没有已知的高效判定法,它是经典的 NP 完全问题。

例题。 考虑有 5 个顶点 $\{A,B,C,D,E\}$ 的图,边为:

$$AB,\ AC,\ BC,\ BD,\ CE,\ DE$$

问:这个图是否有 Hamilton 路径?

从度数最小的顶点入手。$A$ 的邻点是 $B,C$,$D$ 的邻点是 $B,E$,$E$ 的邻点是 $C,D$。试着从 $A$ 出发:

$$A \to B \to D \to E \to C$$

这条路径依次经过 $A,B,D,E,C$,5 个顶点各出现一次,并且每一步都是图中的边($AB,BD,DE,EC$ 都在边集中),所以 Hamilton 路径存在。又因为 $C$ 与 $A$ 之间有边 $AC$,把它加上便得到 Hamilton 圈 $A\to B\to D\to E\to C\to A$。

问题求解应用。 假设一名快递员要把包裹送到 6 个小区,每个小区只访问一次,相邻小区之间有道路相连。这就是在"小区图"中找 Hamilton 路径的问题。

  • 建模:小区为顶点,道路为边。
  • 剪枝:度数为 1 的顶点只能作为路径的端点;若图中有 3 个或更多这样的顶点,则一定没有 Hamilton 路径。
  • 回溯搜索:下面是简洁的实现。
    • def hamilton(graph, path):
    if len(path) == len(graph):
        return path
    for nxt in graph[path[-1]]:
        if nxt not in path:
            result = hamilton(graph, path + [nxt])
            if result:
                return result
    return None

g = {"A":["B","C"], "B":["A","C","D"], "C":["A","B","E"],
     "D":["B","E"], "E":["C","D"]}
for start in g:
    r = hamilton(g, [start])
    if r:
        print(r); break   # ['A', 'B', 'C', 'E', 'D']

    最坏情况下需要检查 $n!$ 条候选路径,所以这种方法只适用于顶点较少的图。

    可用的充分条件。 Dirac 定理指出:若 $n\ge 3$ 的简单图中每个顶点的度数都满足 $\deg(v)\ge n/2$,则该图含有 Hamilton 圈。注意,这只是充分条件。上面的例题中 $\deg(A)=2<5/2$,条件不成立,但图依然有 Hamilton 圈。所以条件不满足时,仍要靠构造或搜索来判断。

    小结:判断 Hamilton 路径时,先用度数做快速排除或快速判定,再用回溯搜索构造具体路径。
