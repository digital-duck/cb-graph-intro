有向哈密顿变换

定义

在图论与组合优化中，哈密顿路径是恰好访问图中每个顶点一次的路径。有向哈密顿变换指的是：把一个问题（如排序、调度、依赖解析）改写成在有向图 $G=(V,E)$ 上寻找一条哈密顿路径的问题，其中每条边 $(u,v)\in E$ 都带有方向，表示"$u$ 必须或可以先于 $v$"。这样，原问题的解就对应于一条遵守所有箭头方向、且不重复不遗漏地经过每个顶点的路径。

变换的关键是两步：

  • 顶点化：把每个待安排的对象（任务、概念、城市）设为一个顶点。
  • 定向化：把"前置/可衔接"关系设为有向边。

    • 例题

    某课程有四个主题：$A$（函数）、$B$（极限）、$C$（导数）、$D$（积分）。教学约束为：函数先于极限，极限先于导数，导数先于积分，同时函数也可直接衔接导数。边集为

    $$E=\{(A,B),\,(B,C),\,(C,D),\,(A,C)\}.$$

    问：能否排出一个每个主题恰好讲一次、且不违反箭头的教学顺序？

    解：从入度为 $0$ 的顶点 $A$ 出发。

  • 试 $A\to C$：此时 $B$ 已无法再被访问（$B$ 的唯一入边来自 $A$），失败。
  • 试 $A\to B\to C\to D$：四个顶点各访问一次，且每条边都在 $E$ 中，成功。

    • 所以哈密顿路径 $A\to B\to C\to D$ 就是合法教学顺序。注意：有向性大大缩小了搜索空间——每一步只需检查出边，而不是所有顶点。

    问题求解应用

    步骤清单（遇到"安排所有对象恰好一次"的问题时）：

  • 列出对象作为顶点；
  • 把"可紧接着"的约束写成有向边；
  • 先找入度为 $0$ 的起点和出度为 $0$ 的终点，它们能迅速剪枝；
  • 用回溯搜索，每步只沿出边扩展，遇到已访问顶点即回退。

    • 下面用代码实现：

    def ham_path(graph, path, n):
    if len(path) == n:
        return path
    for nxt in graph[path[-1]]:
        if nxt not in path:
            r = ham_path(graph, path + [nxt], n)
            if r: return r
    return None

g = {"A": ["B", "C"], "B": ["C"], "C": ["D"], "D": []}
print(ham_path(g, ["A"], 4))   # ['A','B','C','D']

    注意：一般图中判定哈密顿路径是 NP 完全问题，最坏情况需要指数时间 $O(n!)$。但若有向图是有向无环图（DAG），哈密顿路径存在当且仅当其拓扑排序唯一，此时可在 $O(|V|+|E|)$ 内判定。
