哈密顿圈

定义。 在一个图 $G=(V,E)$ 中，哈密顿圈（Hamilton cycle）是一条闭合路径：它恰好经过每个顶点一次，最后回到起点。若一个图含有哈密顿圈，就称它是哈密顿图。注意它与欧拉回路的区别：欧拉回路要求每条边恰好走一次，哈密顿圈要求每个顶点恰好走一次。

可以把它想成旅行规划：一个城市只能访问一次，访问完所有城市后回到出发地。

例题。 考察立方体图 $Q_3$（8 个顶点，每个顶点用三位二进制串表示，两个顶点相邻当且仅当它们恰有一位不同）。试找出一个哈密顿圈。

按格雷码的顺序依次访问：

$$000 \to 001 \to 011 \to 010 \to 110 \to 111 \to 101 \to 100 \to 000$$

检查：相邻两项只差一位，所以每一步都沿着一条边走；8 个顶点各出现一次；最后 $100\to000$ 也只差一位，路径闭合。所以 $Q_3$ 是哈密顿图。

再看一个反例：取一个"哑铃"形图，两个三角形由一条桥边相连。若要走遍所有顶点并回到起点，就必须两次经过这条桥，这样桥的端点会被重复访问。所以该图没有哈密顿圈。

问题求解应用。 判断一个图是否有哈密顿圈，常用三种思路：

  • 必要条件排除。 如果图中有度数为 $1$ 的顶点，或有割点使图分成多个"块"，则不可能有哈密顿圈，因为圈上每个顶点必须恰好有两条边被使用。
  • 充分条件验证。 狄拉克定理：若 $n\ge 3$，且每个顶点的度数都满足 $\deg(v)\ge \dfrac{n}{2}$，则 $G$ 一定有哈密顿圈。例如，完全图 $K_5$ 中每个顶点度数为 $4\ge 2.5$，所以它有哈密顿圈。注意这只是充分条件：长度为 $n$ 的圈 $C_n$ 度数只有 $2$，却显然是哈密顿图。
  • 回溯搜索。 从某个顶点出发，逐步延伸路径，遇到死路就退回。
    • def hamilton(adj, path, n):
    if len(path) == n:
        return path[0] in adj[path[-1]]   # 能否回到起点
    for v in adj[path[-1]]:
        if v not in path:
            if hamilton(adj, path + [v], n):
                return True
    return False

    回溯法在最坏情况下需要检查约 $(n-1)!$ 条路径。判定哈密顿圈是否存在属于 NP 完全问题：给定一个圈，验证它很快（只需检查每个顶点出现一次、相邻处有边），但目前没有已知的多项式时间算法能在一般图上找到它。这正是旅行商问题困难的根源。

    小结。 先用度数与结构做快速排除，再用狄拉克定理等条件尝试证明存在，最后才使用搜索。
