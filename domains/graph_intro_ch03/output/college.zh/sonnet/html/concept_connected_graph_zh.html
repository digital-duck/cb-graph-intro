连通图

定义。 在无向图 $G=(V,E)$ 中，如果任意两个顶点 $u,v\in V$ 之间都存在一条路径（即由边首尾相接构成的顶点序列），则称 $G$ 是连通图。如果存在一对顶点无法互相到达，则 $G$ 是非连通图。非连通图会分裂成若干个互不相连的连通分量，每个连通分量本身是连通的。

连通性是"网络是否完整"的基本判据：城市道路能否让每个路口互通，计算机网络里每台机器能否互相通信，都是在问同一个问题。

在有向图中，要求更严格。若任意两点之间都存在双向的有向路径，则称为强连通。若只在忽略边的方向后连通，则称为弱连通。

例题。 设图 $G$ 的顶点集为 $\{A,B,C,D,E\}$，边集为

$$E=\{AB,\ BC,\ CA,\ DE\}.$$

判断 $G$ 是否连通。

从 $A$ 出发做广度优先搜索（BFS）：

  • 访问 $A$，其邻居为 $B$、$C$；
  • 访问 $B$、$C$，它们的邻居都已访问过；
  • 队列为空，搜索结束。

    • 已访问的顶点为 $\{A,B,C\}$，而 $D$、$E$ 没有被访问到。因此 $G$ 不连通，它有两个连通分量：$\{A,B,C\}$ 和 $\{D,E\}$。

    问题求解应用。 判断连通性的标准方法是：从任一顶点出发做一次 BFS 或 DFS，检查访问到的顶点数是否等于 $|V|$。时间复杂度为 $O(|V|+|E|)$。用 Python 实现如下：

    from collections import deque

def is_connected(graph):
    start = next(iter(graph))
    seen = {start}
    queue = deque([start])
    while queue:
        u = queue.popleft()
        for v in graph[u]:
            if v not in seen:
                seen.add(v)
                queue.append(v)
    return len(seen) == len(graph)

g = {"A": ["B", "C"], "B": ["A", "C"], "C": ["A", "B"],
     "D": ["E"], "E": ["D"]}
print(is_connected(g))  # False

    一个常用的计数结论。 一个有 $n$ 个顶点的连通图至少有 $n-1$ 条边，恰好有 $n-1$ 条边的连通图就是树。因此，如果一个图有 $n$ 个顶点却少于 $n-1$ 条边，可以立刻断定它不连通，不必再做搜索。

    应用练习。 一个通信网络有 8 台服务器和 6 条链路。它能否连通？

    因为 $6<8-1=7$，所以网络必定不连通。要使它连通，至少还需要增加 $1$ 条链路。

    小结。 判断连通性有两步：先用边数做快速检查（$|E|<|V|-1$ 则必不连通），再用 BFS 或 DFS 做确切判断。连通分量的个数还能告诉你，要让整个网络连通，至少需要增加多少条边：若有 $k$ 个连通分量，则至少需要再加 $k-1$ 条边。
