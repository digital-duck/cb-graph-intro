Kruskal 算法

定义。 给定一个连通的带权无向图,最小生成树(MST)是包含所有顶点、边权之和最小且不含环的边子集。Kruskal 算法用"贪心"策略求它:先把所有边按权重从小到大排序,然后依次考察每条边——如果加入这条边不会形成环,就选中它;否则跳过。当选出 $n-1$ 条边($n$ 为顶点数)时停止。

判断"是否成环"的关键工具是并查集(Union-Find):每个顶点属于某个连通分量。若一条边的两个端点已在同一分量,则加入它必然成环;若不在同一分量,就选中该边并合并这两个分量。

例题。 图有顶点 $A,B,C,D,E$,边及权重如下:

| 边 | AB | BC | AC | CD | DE | BD | CE | |---|---|---|---|---|---|---|---| | 权重 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |

按权重排序后依次处理:

  • $AB$(1):$A,B$ 不同分量,选中,合并为 $\{A,B\}$。
  • $BC$(2):$C$ 不在其中,选中,得 $\{A,B,C\}$。
  • $AC$(3):$A,C$ 已同属一个分量,选中会成环,跳过。
  • $CD$(4):选中,得 $\{A,B,C,D\}$。
  • $DE$(5):选中,得到全部 5 个顶点,已有 $4=n-1$ 条边,停止。

    • MST 的边为 $AB, BC, CD, DE$,总权重 $1+2+4+5=12$。

    问题求解应用。 某地要用光缆连接 5 个村庄,每段光缆造价正比于距离,目标是在所有村庄互通的前提下使总造价最低。这正是 MST 问题:把村庄看作顶点,可铺设的线路看作带权边。下面是 Python 实现:

    def kruskal(n, edges):          # edges: (w, u, v)
    parent = list(range(n))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]   # 路径压缩
            x = parent[x]
        return x
    mst, total = [], 0
    for w, u, v in sorted(edges):
        ru, rv = find(u), find(v)
        if ru != rv:            # 不同分量才选中
            parent[ru] = rv
            mst.append((u, v)); total += w
    return mst, total

    复杂度。 排序耗时 $O(E\log E)$,并查集操作近似常数,因此总复杂度为 $O(E\log E)$,等价于 $O(E\log V)$。边数较少的稀疏图上它尤其高效。

    为何贪心是正确的? 其依据是割性质:对于任意把顶点分成两部分的割,跨越该割的最轻边必属于某棵 MST。Kruskal 每次选中的边,正是连接两个不同分量的最轻边,因此每一步都安全。

    常见错误。 忘记检测环,或只比较边权而不检查连通分量;另外,若图不连通,算法得到的是最小生成森林,边数少于 $n-1$。
