循环

定义。 循环(cycle)是指在某个系统中,从一个状态出发,经过若干步骤后又回到起始状态的过程。在图论中,循环是一条起点与终点相同、且中途不重复经过其他顶点的路径。在更广泛的场景中,如水循环、程序中的迭代、经济周期,循环都表示"过程首尾相接、可以重复进行"的结构。判断循环的关键有两点:能够回到起点,以及可以再次重复。

例题。 考虑一个有向图,顶点为 $A, B, C, D$,边为 $A\to B,\ B\to C,\ C\to A,\ C\to D$。

问:图中是否存在循环?

解:从 $A$ 出发,依次沿 $A\to B\to C\to A$ 走,三步后回到 $A$,且中间的顶点 $B, C$ 没有重复,所以这是一个长度为 $3$ 的循环。顶点 $D$ 只有入边而没有出边,一旦进入就无法返回,因此 $D$ 不在任何循环中。

再看一个周期性的例子:某种细菌的生活周期为 $6$ 小时,在时刻 $t=0$ 处于状态 $S$。则对任意整数 $k$,在 $t=6k$ 时它都回到状态 $S$。这里"周期"就是循环走完一圈所需的时间。

问题求解应用。 循环的判断在实际问题中非常常见,下面是三类典型用法。

  • 检测依赖死锁。 假设任务 $T_1$ 等待 $T_2$,$T_2$ 等待 $T_3$,$T_3$ 又等待 $T_1$。把"等待"画成有向边,就得到一个循环 $T_1\to T_2\to T_3\to T_1$,说明这些任务将永远互相等待。因此,有向图中存在循环,等价于不可能给顶点排出一个满足所有依赖的先后顺序(即无法做拓扑排序)。
  • 程序中的循环检测。 在 Python 中,可以用深度优先搜索检测循环:
    • def has_cycle(graph):
    state = {}  # 0=访问中, 1=已完成
    def dfs(u):
        state[u] = 0
        for v in graph.get(u, []):
            if state.get(v) == 0:        # 回到了"访问中"的点
                return True
            if v not in state and dfs(v):
                return True
        state[u] = 1
        return False
    return any(dfs(u) for u in list(graph) if u not in state)

g = {"A": ["B"], "B": ["C"], "C": ["A", "D"], "D": []}
print(has_cycle(g))  # True

    关键思想是:如果搜索时遇到一个仍处于"访问中"的顶点,就说明沿当前路径绕了一圈又回来了,即发现了循环。

  • 周期性计算。 若一个序列每 $p$ 步重复一次,则 $x_{n+p}=x_n$。例如星期几每 $7$ 天循环一次,问"今天是周三,$100$ 天后是星期几?"只需计算 $100 \bmod 7 = 2$,所以是周五。

    • 小结。 遇到"首尾相接"的结构时,先找出一圈包含哪些状态,再确定一圈的长度,这样就能把无限重复的过程化简为一个有限的问题。
