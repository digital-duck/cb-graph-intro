生成树

定义。 设 $G=(V,E)$ 是一个连通的无向图。$G$ 的生成树是这样一个子图 $T$:它包含 $G$ 的全部顶点,只使用 $G$ 的部分边,并且连通且不含回路。要点是"覆盖所有顶点"与"没有多余的边"。若 $|V|=n$,则任何生成树恰好有 $n-1$ 条边:再少一条就不连通,再多一条就会产生回路。

直观理解。 想象要用光纤连接 5 个校区。我们希望每两个校区之间都能通信(连通),但每多铺一条光纤就多一份成本。生成树给出的就是"刚好够用"的铺设方案。

例题。 设图 $G$ 有顶点 $A,B,C,D$,边为 $AB,\ BC,\ CD,\ DA,\ AC$,共 5 条边。

  • $n=4$,所以生成树需要 $n-1=3$ 条边。
  • 取 $\{AB, BC, CD\}$:四个顶点都被连通,没有回路,所以是生成树。
  • 取 $\{AB, BC, AC\}$:这三条边构成回路 $A\to B\to C\to A$,而且顶点 $D$ 没有被覆盖,所以不是生成树。
  • 判断方法:选出 $n-1$ 条边后,检查它们是否连通(等价于检查是否无回路)。

    • 问题求解:最小生成树。 给每条边赋予权重(成本),求总权重最小的生成树。Kruskal 算法是一种贪心策略:

  • 将所有边按权重从小到大排序。
  • 依次考察每条边;若加入它不会形成回路,就保留,否则跳过。
  • 当选中 $n-1$ 条边时停止。

    • 设上图的权重为 $AB=1,\ BC=2,\ AC=3,\ CD=4,\ DA=5$。

  • 取 $AB\,(1)$,保留。
  • 取 $BC\,(2)$,保留。
  • 取 $AC\,(3)$:$A,B,C$ 已经连通,加入会形成回路,跳过。
  • 取 $CD\,(4)$,保留。此时已有 3 条边,停止。

    • 最小总成本为 $1+2+4=7$。

    判断是否会形成回路,常用并查集数据结构实现:

    def find(p, x):
    while p[x] != x:
        p[x] = p[p[x]]
        x = p[x]
    return x

def kruskal(n, edges):          # edges: (w, u, v)
    p = list(range(n)); total = 0
    for w, u, v in sorted(edges):
        ru, rv = find(p, u), find(p, v)
        if ru != rv:            # 不同分量,不成环
            p[ru] = rv; total += w
    return total

    应用与拓展。 生成树出现在网络设计(最小成本布线)、交换机的生成树协议(消除网络环路)和聚类算法中。若图有 $n$ 个顶点且完全连通,Cayley 公式指出共有 $n^{n-2}$ 棵不同的生成树;当 $n=4$ 时有 $16$ 棵。解题时先确认图是否连通,再用"$n-1$ 条边、无回路"来检验答案。
