加权图

定义。 加权图(weighted graph)是在普通图 $G=(V,E)$ 的基础上,给每条边再附加一个数值(称为权重)的图,记作 $G=(V,E,w)$,其中 $w:E\to\mathbb{R}$。权重可以表示距离、时间、费用、容量或相似度。图可以是有向的,也可以是无向的。一条路径的总权重等于路径上所有边的权重之和。需要注意:在加权图中,"最短路径"指总权重最小的路径,而不是经过边数最少的路径。

例题。 设有四个城市 $A,B,C,D$,各条道路的行驶时间(分钟)如下:

| 道路 | 时间 | |---|---| | $A$–$B$ | 4 | | $A$–$C$ | 1 | | $C$–$B$ | 2 | | $B$–$D$ | 5 | | $C$–$D$ | 8 |

求从 $A$ 到 $D$ 的最快路线。

先列出所有简单路径并求和:

  • $A\to B\to D$:$4+5=9$
  • $A\to C\to D$:$1+8=9$
  • $A\to C\to B\to D$:$1+2+5=8$

    • 最小值为 $8$,因此最快路线是 $A\to C\to B\to D$。它经过 3 条边,比前两条路线多一条,却更省时。这说明:边数最少并不等于总权重最小。

    问题求解应用。 当图较大时,枚举所有路径不现实。若所有权重非负,可以使用 Dijkstra 算法:每一步选取"当前已知距离最小且尚未确定"的顶点,再用它来更新邻居的距离。在上例中:

  • 初始化:$d(A)=0$,其余为 $\infty$。
  • 确定 $A$:更新 $d(B)=4$,$d(C)=1$。
  • 确定 $C$(最小):经 $C$ 到 $B$ 为 $1+2=3<4$,所以 $d(B)=3$;$d(D)=1+8=9$。
  • 确定 $B$:经 $B$ 到 $D$ 为 $3+5=8<9$,所以 $d(D)=8$。

    • 结果与枚举法一致。用 Python 实现时,可以借助优先队列:

    import heapq

def dijkstra(graph, start):
    dist = {v: float("inf") for v in graph}
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            if d + w < dist[v]:
                dist[v] = d + w
                heapq.heappush(pq, (dist[v], v))
    return dist

    常见陷阱。 Dijkstra 算法要求权重非负;若存在负权边(如带有补贴的路段),应改用 Bellman–Ford 算法。若要连接所有顶点且总权重最小,需要求的是最小生成树(Prim 或 Kruskal 算法),而不是最短路径,这两类问题不要混淆。

    练习。 把上例中 $C$–$B$ 的权重改为 $5$,重新求 $A$ 到 $D$ 的最短路径,并说明最优路线是否发生变化。
