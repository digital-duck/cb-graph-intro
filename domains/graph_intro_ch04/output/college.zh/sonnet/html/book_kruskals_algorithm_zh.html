Concept Book: Kruskals Algorithm

Graph Intro Ch04 · Generated by SPL

成果

克鲁斯卡尔算法(Kruskal's algorithm)解决的是一个朴素而重要的问题:给定一个带权连通图,如何用总代价最小的方式把所有顶点连通起来?答案是最小生成树(minimum spanning tree, MST)。算法的做法只有一句话:把所有边按权重从小到大排序,依次考察;若某条边不会与已选的边构成环,就选中它,否则丢弃,直到选满 $n-1$ 条边为止。

为什么它是自然的终点

这个算法把前面各章的概念汇集到一处:图与权重(问题的描述)、环与连通分量(判断一条边能否加入)、排序(决定考察顺序)、贪心策略(每一步取当前最优)。它还附带一个结论:在这个问题上,局部最优的选择能够得到全局最优,这由"割性质"保证。该性质指出,横跨任意一个割的最轻边必属于某棵最小生成树。

一个具体例子

设有 4 个城市 $A,B,C,D$,要修路使它们互相连通,各条路的造价如下:

| 边 | $AB$ | $BC$ | $AC$ | $CD$ | $BD$ | |---|---|---|---|---|---| | 造价 | 1 | 2 | 3 | 4 | 5 |

排序后依次考察:

  • $AB$(1):加入。
  • $BC$(2):加入。
  • $AC$(3):$A$ 与 $C$ 已经连通,再加会成环,丢弃。
  • $CD$(4):加入,此时已有 $3=n-1$ 条边。

    • 总造价为 $1+2+4=7$。

    判断"是否成环"靠并查集(union-find):每个顶点属于一个集合,若边的两端属于同一集合就丢弃,否则合并两个集合。

    def kruskal(n, edges):
    parent = list(range(n))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    mst, total = [], 0
    for w, u, v in sorted(edges):
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            mst.append((u, v, w))
            total += w
    return mst, total

    瓶颈在排序,所以时间复杂度为 $O(E\log E)$。

    与各应用领域的联系

    本节没有列出具体的应用领域,下面是这个算法最常见的几类用途。

  • 网络与基础设施设计:光纤、电网、管道的铺设。顶点是站点,边权是造价,最小生成树就是最省钱的联网方案。
  • 聚类分析:在最小生成树中删掉最重的 $k-1$ 条边,就得到 $k$ 个簇。这就是单连接层次聚类。
  • 图像分割与近似算法:最小生成树常作为中间结构,例如在旅行商问题中给出 2-近似解。
