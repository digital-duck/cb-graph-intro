结语与应用(Payoff)

隶属网络究竟达成了什么

隶属网络(affiliation network)是一种二部结构:一类节点是"行动者"(人、论文、基因),另一类节点是"团体"(俱乐部、期刊、通路),边只连接两类之间,表示"隶属于"。设行动者集合为 $A$,团体集合为 $G$,关联矩阵 $B\in\{0,1\}^{|A|\times|G|}$,其中 $B_{ig}=1$ 表示行动者 $i$ 属于团体 $g$。

它的力量在于投影:

$$ P_A = BB^{\top},\qquad P_G = B^{\top}B . $$

$(P_A)_{ij}$ 是 $i$ 与 $j$ 共同所属的团体数,$(P_G)_{gh}$ 是 $g$ 与 $h$ 共有的成员数。一张二部图由此同时给出"谁与谁相近"和"哪些团体相互重叠"两个视角。前面各章的图、邻接矩阵、度、连通性、二部性与矩阵乘法,在这里汇合成一个可计算的整体,所以它是自然的终点。

一个小例子

三位学生与两个社团:$B=\begin{pmatrix}1&0\\1&1\\0&1\end{pmatrix}$。则

$$ BB^{\top}=\begin{pmatrix}1&1&0\\1&2&1\\0&1&1\end{pmatrix}. $$

第二位学生与另外两人各共享一个社团,他是连接两个圈子的"桥"。用代码验证:

import numpy as np
B = np.array([[1,0],[1,1],[0,1]])
print(B @ B.T)   # 学生-学生
print(B.T @ B)   # 社团-社团

与各应用领域的联系

本节未列出具体的应用领域,以下以三个典型场景示意同一套方法如何迁移,你可以替换成自己关心的领域:

  • 社交与组织分析:用 $P_A$ 的非对角项找出"桥"人物,用 $P_G$ 发现重叠的社团。
  • 推荐系统:用户与商品构成二部图,$BB^{\top}$ 的大值表示口味相近的用户,可据此推荐。
  • 生物信息学:基因与通路构成二部图,$P_G$ 显示哪些通路共享基因,提示功能耦合。

    • 三者的建模步骤相同:①确定两类节点;②写出 $B$;③选择投影;④解读结果。

    解题提示

    投影会丢失信息:一个有 5 人的团体与五个各有 2 人的团体,可能给出相似的 $P_A$。分析时应回到 $B$,必要时按团体规模加权,例如把 $B$ 的列除以 $\sqrt{\text{列和}}$。

    邀请

    选一个你熟悉的数据集,例如课程选课表或电影观众名单,构建 $B$,计算两个投影,并找出一个"桥"节点。然后追问:这座桥删除后,网络是否断开?这个问题会把你带入某个应用的深处。
