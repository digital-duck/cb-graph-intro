计算机网络

定义。 计算机网络是由若干台计算机或设备通过通信链路连接起来、并遵循共同规则（协议）来交换数据的系统。网络中的设备称为节点，包括主机、路由器和交换机等。常见的分类有：局域网（LAN，覆盖一个房间或校园）、广域网（WAN，覆盖城市乃至全球）。互联网就是由无数个网络互联而成的"网络的网络"。

网络通信依赖分层模型。以常用的 TCP/IP 四层模型为例：应用层（HTTP、DNS）、传输层（TCP、UDP）、网络层（IP）、链路层（以太网、Wi-Fi）。每一层只处理自己的任务，并把结果交给相邻的层。

两个核心指标。 带宽 $B$ 表示链路每秒能传输的比特数；时延则由传输时延和传播时延组成：

$$ T = \frac{L}{B} + \frac{d}{v} $$

其中 $L$ 为数据量（比特），$d$ 为链路长度，$v$ 为信号传播速度（光纤中约为 $2\times10^{8}$ m/s）。

例题。 通过一条长 $2000$ km、带宽 $100$ Mbit/s 的光纤链路发送一个 $10$ MB 的文件，忽略排队与处理时延，总时延是多少？

  • 数据量：$L = 10\times 8\times10^{6} = 8\times10^{7}$ bit
  • 传输时延：$\dfrac{8\times10^{7}}{10^{8}} = 0.8$ s
  • 传播时延：$\dfrac{2\times10^{6}}{2\times10^{8}} = 0.01$ s
  • 总时延：$T = 0.8 + 0.01 = 0.81$ s

    • 可见，对于大文件，传输时延占主导，提高带宽会明显见效。

    问题求解应用。 再看另一种情形：只发送一个 $100$ 字节的请求包（$800$ bit），链路相同。传输时延为 $\dfrac{800}{10^{8}} = 8\ \mu\text{s}$，而传播时延仍是 $10$ ms。此时传播时延占绝对主导，把带宽提高十倍几乎没有任何改善。这解释了为什么网页加载这类"小而多"的请求更依赖低延迟（例如就近部署服务器、使用 CDN），而下载大文件才更依赖高带宽。

    在实际排查网络问题时，可以用下面的命令来观察延迟：

    ping example.com        # 测量往返时延 RTT
traceroute example.com  # 查看数据包经过的每一跳路由器

    若 RTT 很高，先看 traceroute 中是哪一跳开始变慢，再判断是链路距离、拥塞还是服务器本身的问题。

    小结。 理解计算机网络的关键是：协议分层让复杂系统可以拆分处理；带宽与时延是两个不同的指标；解决问题时，先判断瓶颈究竟是传输时延还是传播时延，再决定优化方向。
