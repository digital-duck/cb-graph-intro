Web Graph

A web graph is a directed graph in which each node represents a webpage and each directed edge represents a hyperlink from one page to another. If page A contains a link to page B, the graph includes a directed edge A → B. This structure captures the entire navigable topology of the web (or any subset of it) in a form that algorithms can analyze.

The web graph has two defining structural properties. First, it is sparse: most pages link to only a handful of others, so the number of edges is much smaller than the theoretical maximum of $n^2$ for $n$ nodes. Second, it exhibits a power-law degree distribution: a tiny fraction of pages (news sites, Wikipedia, major social platforms) attract an enormous number of inbound links, while the vast majority of pages receive almost none. This skew is captured by the observation that the fraction of nodes with in-degree $k$ scales roughly as $k^{-\alpha}$ for some exponent $\alpha \approx 2$–$3$.

Worked example. Suppose you are building a small crawler that visits five pages and records their links:

  • home.html → about.html, blog.html
  • blog.html → post1.html, home.html
  • about.html → home.html
  • post1.html → blog.html
  • post2.html → home.html

    • Represent this as an adjacency list. The in-degree of home.html is 3 (from blog, about, and post2), making it the hub. post2.html has in-degree 0 — a dangling node that nothing links to, a common artifact in real crawls.

    Problem-solving application. Web graphs are the foundation of link-analysis algorithms such as PageRank, which assigns each node an importance score based on how many high-quality pages point to it. In practice, you build the web graph incrementally during a crawl: start from a seed URL, fetch the page, parse all <a href> tags, add directed edges to your graph, and enqueue unvisited targets. Efficient implementations represent the graph as a compressed sparse row (CSR) matrix because storing $10^{12}$ edges as an explicit adjacency list is infeasible. Detecting strongly connected components (sets of pages mutually reachable from each other) within the web graph reveals the famous "bow-tie" structure of the web: a giant core, upstream nodes that feed into it, and downstream nodes that can only be reached from it.
