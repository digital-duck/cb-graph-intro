Underlying Graph

A directed graph (digraph) assigns a direction to every edge — each edge points from a source vertex to a target vertex. The underlying graph of a digraph is the undirected graph you get by stripping away those directions, keeping the same vertices and the same connections but treating every edge as a simple, two-way link.

Formally, if $G = (V, E)$ is a digraph where each edge is an ordered pair $(u, v)$, then its underlying graph $G' = (V, E')$ replaces every directed edge $(u, v)$ (and its possible reverse $(v, u)$) with a single undirected edge $\{u, v\}$. If both $(u, v)$ and $(v, u)$ exist in $G$, they collapse to one edge in $G'$.

Worked example. Consider a digraph with vertices $\{A, B, C\}$ and directed edges $(A, B)$, $(B, C)$, $(A, C)$. Visually, every arrow points in one direction. The underlying graph simply connects $A$–$B$, $B$–$C$, and $A$–$C$ without any arrowheads — a triangle. Now add the reverse edge $(C, A)$ to the digraph. In the underlying graph, $A$–$C$ is already present, so nothing changes: the underlying graph is still the same triangle.

Why it matters in problem-solving. The underlying graph is the key tool for checking weak connectivity of a digraph. A digraph is weakly connected if its underlying graph is connected — meaning you can reach any vertex from any other vertex when you're allowed to travel edges in either direction. This is a weaker condition than strong connectivity, which requires a directed path in both directions between every pair of vertices.

In practice, suppose you're modeling a one-way street network and want to verify that no neighborhood is completely isolated. You convert the street map to its underlying graph and run a standard breadth-first search (BFS) or depth-first search (DFS) on it. If BFS visits every intersection, the network is weakly connected — no neighborhood is cut off entirely, even if you can't drive back the same way you came. If some vertices are unreachable in the underlying graph, those locations are structurally isolated regardless of traffic direction, and the network has a design flaw worth fixing.

The underlying graph thus acts as a diagnostic layer: it separates topology (what is connected to what) from flow (which direction information or traffic travels).
