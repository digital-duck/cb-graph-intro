Epidemic Protocol

An epidemic protocol (also called a gossip protocol) is a communication strategy for distributed systems in which each node periodically selects a small, random subset of peers and exchanges information with them. Over successive rounds, information spreads exponentially through the network—mirroring how a biological infection propagates through a population. The result is a robust, decentralized mechanism for achieving eventual consistency across thousands of nodes without any central coordinator.

The core idea has three moving parts: fanout (how many peers each node contacts per round), round interval (how often a node gossips), and message age (how long a rumor stays "fresh" before a node stops spreading it). Together these parameters control the tradeoff between convergence speed, bandwidth, and message overhead.

Worked example. Suppose a cluster has 1,000 nodes. Node A receives a configuration update and begins gossiping with fanout $k = 3$. After round 1, roughly $3$ nodes know the update. After round 2, those nodes each contact 3 more, so about $3^2 = 9$ nodes are informed. In general, after $r$ rounds approximately $\min(N,\, k^r)$ nodes hold the update, so the information reaches the full cluster in roughly $r = \log_k N$ rounds. With $k=3$ and $N=1000$, that is about $\lceil \log_3 1000 \rceil = 7$ rounds—very fast, and achieved with no single point of failure.

Problem-solving application. The following Python snippet simulates one round of gossip in a small cluster, illustrating how you would implement the fanout selection:

import random

def gossip_round(nodes: dict[str, set], updated: set[str], fanout: int = 3):
    for node in list(updated):
        peers = random.sample([n for n in nodes if n != node], k=fanout)
        for peer in peers:
            nodes[peer].update(nodes[node])   # share all known facts
            updated.add(peer)
    return updated

# Bootstrap: node "A" learns fact "cfg_v2"
cluster = {n: set() for n in ["A","B","C","D","E","F","G","H"]}
cluster["A"].add("cfg_v2")
informed = {"A"}

for round_num in range(1, 5):
    informed = gossip_round(cluster, informed)
    print(f"Round {round_num}: {len(informed)} nodes informed")

Running this typically shows all eight nodes converged within 2–3 rounds. When designing a real system, you tune fanout to balance convergence speed against network traffic, and you set a message time-to-live to prevent stale updates from circulating indefinitely. Epidemic protocols underpin systems like Apache Cassandra's membership layer and Amazon DynamoDB's anti-entropy engine—anywhere you need resilience more than strict ordering guarantees.
