Traveling Salesman Problem

A salesperson needs to visit a set of cities exactly once and return home — what is the shortest possible route? This deceptively simple question defines the Traveling Salesman Problem (TSP): given $n$ cities and the distances between every pair, find the minimum-cost Hamiltonian cycle (a closed tour that visits each city exactly once).

TSP is famous not just as a puzzle but as a canonical NP-hard problem. For $n$ cities, the number of distinct tours is $(n-1)!/2$, which grows faster than any polynomial. For 20 cities that is already over $10^{16}$ tours — exhaustive search is hopeless in practice, so real solutions rely on smart heuristics and approximation algorithms.

Nearest-neighbor heuristic — worked example. Suppose you have four cities: A, B, C, D with distances:

| | A | B | C | D | |---|---|---|---|---| | A | — | 2 | 9 | 6 | | B | 2 | — | 5 | 4 | | C | 9 | 5 | — | 3 | | D | 6 | 4 | 3 | — |

Start at A. Nearest unvisited city: B (distance 2). From B, nearest unvisited: D (distance 4). From D, nearest unvisited: C (distance 3). Return home: C → A (distance 9). Tour: A → B → D → C → A, total cost $2 + 4 + 3 + 9 = 18$.

Is this optimal? The tour A → B → C → D → A costs $2 + 5 + 3 + 6 = 16$. The greedy heuristic missed it — a reminder that "always pick the closest next city" does not guarantee a globally optimal solution.

Problem-solving with code. For small instances you can try all permutations; for larger ones, use established libraries:

from itertools import permutations

distances = {
    ('A','B'):2, ('A','C'):9, ('A','D'):6,
    ('B','C'):5, ('B','D'):4, ('C','D'):3
}

def dist(a, b):
    return distances.get((a,b), distances.get((b,a)))

cities = ['A','B','C','D']
best = float('inf')
best_tour = None

for perm in permutations(cities[1:]):   # fix A as start
    tour = ['A'] + list(perm) + ['A']
    cost = sum(dist(tour[i], tour[i+1]) for i in range(len(tour)-1))
    if cost < best:
        best, best_tour = cost, tour

print(best_tour, best)   # ['A', 'B', 'C', 'D', 'A'] 16

For real-world scale — logistics routing, circuit board drilling, genome sequencing — practitioners use OR-Tools, LKH, or metaheuristics like simulated annealing, which trade provable optimality for tractable runtime. Understanding TSP teaches you when to seek exact solutions versus when to settle for "good enough, fast."
