Euler Tour

An Euler tour (also called an Eulerian circuit) is a walk through a graph that traverses every edge exactly once and returns to its starting vertex. The concept dates to Leonhard Euler's 1736 solution to the Königsberg Bridge Problem, widely regarded as the birth of graph theory. A related notion, an Euler path, traverses every edge exactly once but may end at a different vertex than it started.

When does an Euler tour exist? This is a question with a clean, verifiable answer — making it one of the few graph problems solvable in polynomial time without brute force.

> Theorem (Euler, 1736). A connected undirected graph has an Euler tour if and only if every vertex has even degree.

The proof idea is intuitive: whenever the walk enters a vertex, it must also leave. If any vertex has an odd number of edges, the walk will eventually get "stuck" there with no unused edge to exit on. For directed graphs, the condition upgrades: every vertex must have equal in-degree and out-degree.

Worked example. Consider a graph with vertices $\{A, B, C, D\}$ and edges $AB, BC, CD, DA, AC$. Computing degrees: $\deg(A) = 3$, $\deg(B) = 2$, $\deg(C) = 3$, $\deg(D) = 2$. Because $A$ and $C$ have odd degree, no Euler tour exists — but an Euler path from $A$ to $C$ (or $C$ to $A$) does, since exactly two vertices are odd.

Now remove edge $AC$, making all degrees even. An Euler tour now exists: $A \to B \to C \to D \to A$ uses every edge exactly once.

Finding an Euler tour in code. Hierholzer's algorithm constructs an Euler tour in $O(E)$ time. It works by greedily following unused edges from the start, then splicing in sub-tours whenever it revisits a vertex with unused edges remaining.

from collections import defaultdict

def euler_tour(graph, start):
    adj = defaultdict(list)
    for u, v in graph:
        adj[u].append(v)
        adj[v].append(u)

    stack, tour = [start], []
    while stack:
        v = stack[-1]
        if adj[v]:
            stack.append(adj[v].pop())
        else:
            tour.append(stack.pop())
    return tour[::-1]

edges = [(0,1),(1,2),(2,3),(3,0),(0,2)]
print(euler_tour(edges, 0))

A practical use: DNA fragment assembly. Short sequenced reads are edges in a de Bruijn graph, and reconstructing the genome corresponds to finding an Euler tour — making this 18th-century puzzle the backbone of modern bioinformatics pipelines.
