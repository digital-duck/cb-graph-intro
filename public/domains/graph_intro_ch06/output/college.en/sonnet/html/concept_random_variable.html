Random Variable

A random variable is a function that assigns a numerical value to each outcome of a random experiment. The name is slightly misleading — it is not a variable in the algebraic sense, and it is not purely random. It is a rule that translates the messiness of chance events into numbers we can compute with.

Formally, if $\Omega$ is the sample space of an experiment, a random variable $X$ is a function $X: \Omega \to \mathbb{R}$. Two types matter most:

  • Discrete random variables take a countable set of values (e.g., the number of heads in five coin flips).
  • Continuous random variables take values over an interval (e.g., the exact time a customer waits in line).

    • Worked Example. Roll a fair six-sided die. The sample space is $\Omega = \{1, 2, 3, 4, 5, 6\}$. Define $X$ as the value showing on top. Then $X$ is a discrete random variable where each outcome maps to itself: $X(1) = 1$, $X(2) = 2$, and so on, each with probability $\frac{1}{6}$.

    Now define a different random variable on the same experiment: $Y = 1$ if the roll is even, $Y = 0$ otherwise. Same sample space, different function — $Y$ is a Bernoulli random variable with $P(Y = 1) = \frac{1}{2}$.

    This illustrates a key point: multiple random variables can be defined on the same experiment. The choice of $X$ versus $Y$ reflects what question you are asking.

    Problem-Solving Application. Suppose a game pays you $\$3$ if a die shows a 6, and charges you $\$1$ otherwise. Define the random variable $W$ as your net winnings:

    $$W = \begin{cases} 3 & \text{with probability } \tfrac{1}{6} \\ -1 & \text{with probability } \tfrac{5}{6} \end{cases}$$

    The expected value $E[W]$ summarizes the long-run average outcome:

    $$E[W] = 3 \cdot \frac{1}{6} + (-1) \cdot \frac{5}{6} = \frac{3 - 5}{6} = -\frac{1}{3}$$

    On average, you lose about 33 cents per play. A random variable turns a vague question — "is this game worth playing?" — into a precise calculation. That translation from outcome to number, followed by computation, is exactly what random variables are designed to enable.
